# ZoneMind 0.9.4 — Offline Foundation

- cache IndexedDB per workspace negozio;
- apertura del Mapper senza API dopo almeno un caricamento online;
- coda persistente per CREATE_ASSIGNMENT e MOVE_ASSIGNMENT;
- applicazione immediata delle operazioni allo stato locale;
- indicatori Online/Offline e numero di operazioni in coda;
- sincronizzazione manuale FIFO di base;
- nessuna migrazione del database server.
